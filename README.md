# Missing Binary String

## About the Project

This repository contains my solution to the **Missing Binary String** programming problem.

I solved this problem by myself using the **C programming language**. I worked on understanding the problem, developing my own approach, and implementing the solution.

## My Approach

My solution uses:

- `qsort()` to sort the array of binary strings.
- `bsearch()` to check whether a candidate string exists in the array.
- A custom function to convert integers into binary strings of a fixed length.

The idea is to generate binary string candidates and return the first one that does not appear in the given array.

## What I Learned

While working on this problem, I practiced:

- Working with arrays of strings in C.
- Using pointers and functions from the C standard library.
- Sorting and searching with `qsort()` and `bsearch()`.
- Converting integers to binary representations.
- Managing dynamically allocated memory.
